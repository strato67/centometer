# Centometer

Centometer is a platform for comprehensive stock market insights. It leverages AI-driven analysis, real-time data, and advanced visualization tools to help users make informed investment decisions.

Visit the live platform: [cmeter.vercel.app](https://cmeter.vercel.app)

## Key Features

- **Stock Data**: Access up-to-date information on thousands of stocks.
- **Sentiment Analysis**: Analyze millions of data points for real-time insights into market sentiment.
- **Advanced Visualization**: Interactive charts and dashboards to uncover trends and patterns.
- **User Authentication**: Secure login, signup, and account management powered by Supabase.
- **AI Integration**: Uses Gemini AI for enhanced analytics.
- **Cloud-Native**: Built with Next.js and deployed on Vercel.
- **Tech Stack**: TypeScript, Next.js, Supabase, DynamoDB, AWS Lambda, Python, Tailwind CSS, Shadcn UI.

## Getting Started

First, clone the repository and install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
